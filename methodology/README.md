# 方法论正文

`solution-delivery-loop.md` 是方案收敛与交付闭环工作法的完整说明，面向希望理解、评审和改进方法的人。

正式技能位于 `plugins/nevis-toolkit/skills/solution-delivery-loop/`：`SKILL.md` 提供执行主干，`references/` 提供按需读取的操作细则。该目录是 Claude Code 插件 `nevis-toolkit` 中的技能，通过市场 `nevis-plugins` 分发。

正文维护工具无关的概念、方法、协作原则、信息职责及完成条件。固定目录、配置格式、环境变量、Hook、工具调用与角色配置由技能细则和脚本说明承载，不反向复制进方法论正文。

方法论与技能不追求逐字一致；方法上的新增与变更需要同步检查技能中的执行规则，平台专有实现则只需符合方法，不要求正文记载。修改核心方法时逐条审阅对应位置，不能只依赖关键词检查。
